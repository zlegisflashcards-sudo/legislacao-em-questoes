# Scoped reading pilot

This is separate from scoped LegisCast, PDF, the existing questions/Anki entitlements, and the commercial catalog. Do not change their production configuration as part of this pilot.

1. Review the precise articles in scope, including grouped blocks. Use the editorial reference/version inventory and the same sanitizer as the route. The seed plan rejects version drift, an unexpected article/structure, an incomplete manifest, and article headings outside the certified article. It is not a replacement for checking the actual grouped content.
2. In a verified nonproduction database, apply the proposed migration with the feature flag absent. Make the transactional seed using the reviewed metadata and matching raw references from authorized input; do not commit raw source rows, quiz IDs, generated production SQL, or secrets. Set `SCOPED_READING_REVIEW_FILES='["snapshot.json","matching-raw.json","review-only.sql"]'` for `pnpm exec vitest run lib/scoped-study-seed.test.ts` to generate offline, with no connection to any database. Optional `PGLITE_MODULE` runs DB fixtures; `scripts/test-scoped-reading-cert-schema.mjs` separately verifies schema, same-law FK and privilege behavior.
3. Review the generated SQL and verify the target environment independently before any execution. It rechecks active/publication/gratuity, exact configured roots, every reference/version and byte hash, and exact certified count. Any drift rolls back the entire transaction. It changes structural bindings and adds certifications; it does not modify legal text, create an account, or alter published audio/PDF.
4. Configure only the tested `slug:scope-uuid` as `SCOPED_READING_PILOTS` on the staging app. No entry means no new public reading path. Missing, foreign, stale or revoked certificates yield no block. Scope/flag problems never fall back to the complete law. The original full-law reading, LegisCast and PDF paths remain untouched; no conversion of the PDF into a scoped file.
5. As a purpose-made test student without full access, confirm login returns to the right context, reading contains only the approved pilot blocks and no attachments, and Anki downloads exactly the approved question set. Inspect the downloaded APKG's SQLite notes and compare the ID/ordem set, not merely the counter. Test anonymous, sibling buyer and ordinary full-law buyer separately; verify the paid PDF downloads unchanged. The local APKG round-trip does not substitute for this staging-account check.
6. Keep the production switch off until staging passes and live configuration is verified. Activate only the reviewed pair; remove the flag first if rollback is required. Do not publish an audio CTA or a new audio capability as part of this reading release. A mutable storage path is not a certificate for the entire exact audio object.

Known existing test baseline: the legacy `law-material-download.test.ts` expects a previously removed PDF detail in old LegisCast UI; that assertion fails on the unmodified main checkout. The targeted compatibility test separately exercises the full PDF download response.
